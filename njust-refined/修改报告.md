# 南京理工大学校园模型精细化修改报告

**交付工程：NJUST_Final.blend · Blender 5.1.2 · 2026-09-10**

本次在已有 `NJUST_Violet_Spring.blend` 上进行增量加工，保留校园主体布局，增加建筑立面、道路、植物、校园设施、灯光与镜头。工程的定位是**沿用原有布局的校园建筑可视化**。原型并非测绘模型，因此本次不能据此宣称完成了南京理工大学真实校园的等比例数字孪生。

## 1. 原始模型、版本和空间关系

- 原文件另存为 `NJUST_v00_Original.blend`；原场景保留为 `Original_Backup`。
- 精细化场景为 `Refined_Version`；替换掉的已知对象进入隐藏的 `Legacy_Superseded`，保留来源及替换原因。
- v01：建筑和道路；v02：植物、设施和材质；v03：灯光与镜头；v04—v07：视觉检查与修正。最终整合于 `NJUST_Final.blend`。
- 原模型整体做 **2.2 倍统一尺度校准**，使用 Metric、Unit Scale 1。24 个主体建筑的归一化位置与原模型一致，程序检查无位置误差；没有重排建筑群。
- 此尺度校准是让门、车、人和主要楼层进入可用的米制范围，并非恢复实际校园占地尺寸。道路、体育场和部分楼层仍受原型压缩布局限制。

## 2. 建筑改进

覆盖致远楼主体、图书馆翼楼、教学建筑、工程楼、历史风格建筑及宿舍组团，共 24 个主体立面对象。

- 新增 2,046 个共享窗组件实例，3 种窗型，每种包含亮灯和熄灯版本。
- 窗框、窗台、玻璃和室内暗面分层，部分宿舍窗增加空调室外机；夜景随机亮窗比例约 **30.5%**。
- 添加入口门、玻璃雨棚、屋顶设备、排水管、屋面边缘和通风构件。
- 保留图书馆原有弧形轮廓，补齐弧面玻璃；不为未核实建筑编造新的独特立面。
- 主要构件增加适量倒角与法线修整；墙面增加克制的粗糙度、表面起伏与近地色差。
- 入口采用 2.32 m 门、150 mm 台阶和约 1:12 坡道模块。坡道属于模型中的表达，未作建筑法规或无障碍竣工验收。

## 3. 道路、水体与体育设施

道路增加抬高的人行区域、路缘石、盲道、方向箭头、排水口、井盖式格栅和减速带。缩小原模型过厚的部分地面标线；修正地面遮住路面的尺度转换问题。

湖面和河面采用独立水材质，地面保留可编辑 Boolean 开挖。原本覆盖整个水域的岸边实心面改成岸线环带；增加浅水底、细微水纹与局部芦苇。降低林间步道和部分桥面接驳高差，清理桥边树木冲突。

体育区保持原有轮廓，添加球门、球网、篮球架和高杆灯。球门按小型练习场处理，篮球架高度约 3.05 m。**运动场不是标准 400 m 跑道，也不是标准 11 人制足球场；篮球场占地同样沿用压缩原型。** 未通过拉伸场地破坏既有空间关系。

## 4. 植物与校园生活

- 8 种树木资产：5 种阔叶变体、3 种水杉变体，各有 3 级 LOD。
- 5 种灌木、3 种花簇、局部草叶资产。树冠采用枝干和叶片，不再以原始实心多面体树冠为主。
- 行道树 113 个候选点、水杉林 61 个候选点、外围树带 120 个候选点，使用共享资产并随机旋转、缩放。
- 花簇使用 3,390 个候选点，保留概率 0.9；每簇包含小型四瓣花、茎与基部叶片。归档了原模型近景中过大的紫色花瓣面。
- 设施包括路灯、长椅、垃圾箱、消防栓、电箱、路桩、花箱、自行车架、自行车、电动车、候车棚、快递柜、售货机、公告栏和校车站牌。
- 人物约 1.71 m、车辆宽约 1.8 m、长椅座高约 0.46 m、路灯高约 5.7 m。模型中有少量人物与车辆，避免密集堆放。
- 清理原始批处理网格中被整体放大的长椅，使用米制共享资产替代。

## 5. 材质、灯光和学校标识

材质包含浅色墙面、暖色墙面、砖墙、混凝土、沥青、人行道石材、红屋面、金属、玻璃、水、草地、树皮、木材、跑道、球场与花叶；使用程序化纹理调整色差、Roughness 与 Bump。它们是轻写实的程序材质，不是现场采集的扫描 PBR 贴图。

提供 **DAY / GOLDEN_HOUR / NIGHT** 三套环境与灯组。白天太阳高度约 48°；夕阳约 20°；夜景使用冷色环境、暖色窗光、路灯、入口灯和体育照明。HDRI 为 Poly Haven 的 CC0 `Kloppenheim 06 (Pure Sky)`，已打包。色彩使用 AgX，保持建筑轮廓清楚，未使用夸张景深或强烈泛光。

校门使用“南京理工大学”及英文全称，校徽取自校方页面图像中已确认的左侧徽记，未使用该新闻页面的整段新闻站标识。校风文字为“团结 献身 求是 创新”；校训为“进德修业 志道鼎新”。**校名为可编辑中文字形，并未声称复刻官方题字笔迹。** 校徽来源分辨率有限，超近特写可进一步更换为校方高分辨率矢量图。

## 6. Geometry Nodes、实例与 LOD

工程有 10 套 Geometry Nodes 分布系统：

| 系统 | 用途 |
|---|---|
| GN_Road_Trees | 道路树阵列 |
| GN_Woodland_Random | 水杉林 |
| GN_Context_Tree_Belt | 外围背景树带 |
| GN_Shrubs | 灌木 |
| GN_Close_Flowerbeds | 花簇 |
| GN_Local_Grass | 局部草叶 |
| GN_Lamp_Array | 路灯阵列 |
| GN_Bicycle_Parking | 自行车停车 |
| GN_Parking_Vehicles | 停车车辆 |
| GN_Pedestrian_Life | 少量人物 |

均暴露 Density、Random Seed、Scale Min、Scale Max、Rotation、Distance。Density 控制候选点的保留比例，并非无限增加点数。植物通过相机参考点与距离选择实例分支，未 Realize Instances。

功能集合内建立 LOD0、LOD1、LOD2 子集合；普通 LOD2 细节由 `update_lod()` 按相机距离隐藏，默认近景阈值约 95 m，世界坐标批处理对象使用包围盒中心补偿。树木有真实的不同网格精度；路灯、人物等非树木系统复用相同模块，其分支并非三个独立精度网格。

最终场景统计为 3,907 个对象、1,083 个被场景对象使用的独立 Mesh 数据块、2,343 个 Collection Instance。统计包含隐藏的可回退对象，**并不等于当前帧实际绘制量**。资产库中的可复用集合和完整名单见 `reports/delivery_audit.json`。

普通近景细节的距离更新由渲染脚本执行，手动移动相机后可在 NJUST 面板重新选择当前镜头刷新；不是一个永久安装的全局自动 LOD 插件。实例共享、少量灯光、Simplify 和按距离隐藏共同控制开销。

10 张静帧使用 Cycles、OptiX GPU、128 Samples 与降噪，分辨率 2400×1500。漫游为 Eevee、32 Samples、1920×1080、24 fps、432 帧，即 **18 秒**，输出 H.264 MP4。

相机使用 Bezier 路径、Follow Path 和独立 Look At 目标；对齐两者的关键帧时序，配置缓入缓出，末段逐渐调整焦距。林区路径提高到树冠上方，减少树叶遮挡。逐帧包围盒检查没有进入 24 个主体建筑；该检查不等同于对所有微小配件做完整碰撞检测。

本机为 RTX 5060 Ti 16 GB。静帧和动画采用串行任务。并发试渲染曾触及 GPU 与共享内存限制；最终流程因此顺序执行。具体耗时见 `reports/render_timings.json` 与 `reports/animation_render.json`，不将本机结果等同于所有设备的实时性能保证。

## 8. 核验与后续优先事项

已检查：原始备份、归一化主体位置、场景重新打开、三套 World 保存、外部图像和字体打包、10 套 GN 输入、人物/车辆/门的设计尺寸、道路与地面高差、水域岸线、近景花瓣尺度、旧长椅批次、动画主体碰撞，以及最终图像和视频输出。

后续值得继续投入的内容：

1. **测绘依据**：以正式总平面、GIS 或实测数据恢复校园真实范围、朝向、道路长度与建筑间距。本次继承的压缩校园无法直接充当真实地图。
2. **建筑真实性**：校门整体轮廓、兵器博物馆、体育场及普通宿舍/教学楼的细部尚缺逐立面的可靠参考；现阶段保留原型，不把通用模块当作实景复刻。
3. **体育尺寸**：需要在允许重新校准布局后恢复标准场地，当前属于练习场比例。
4. **桥梁与附属结构**：原型中的栏杆、桥柱、台基、部分旧门窗和屋顶构件仍可能偏厚，需要近距离逐对象校准。只对已确认的问题进行了修正，未宣称全部构件都达到建筑施工精度。
5. **植物与人物**：叶片、花簇和人物仍为轻量程序资产；可加入照片植物贴图、扫描树皮和更高质量人物，继续改善特写。
6. **标识与命名**：校徽适合中远景；需要高分辨率校方标识。原工程中的“紫霞湖”等内部名称未得到逐项官方地图定位确认，不能作为实际地名导航依据。
7. **LOD 平滑**：当前树木切换为距离阈值，快速移动时可能存在细微跳变；可扩展滞回阈值、渐隐与更严格的遮挡剔除。
8. **铺装接缝**：部分继承的过街标线在顶视图中呈深色，仍需逐段整理标线与道路、路缘的交接。总体道路和水面遮挡已修复，但这不代表所有旧批处理几何都已彻底重做。
